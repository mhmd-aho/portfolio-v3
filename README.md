# 🚀 Mohamad Abou Hamoud | Developer Portfolio v3

A modern, high-performance, visually striking personal portfolio website engineered with **React 19**, **TypeScript**, **Vite**, **Tailwind CSS v4**, and **GSAP (GreenSock Animation Platform)**. Designed with smooth momentum scrolling, kinetic text reveals, system-aware theme toggle (Dark/Light mode), and full mobile responsiveness.

---

## ✨ Key Features

- **⚡ Blazing Fast Build & Performance:** Powered by Vite and React 19 for sub-second page loads and instant HMR.
- **🎨 Interactive GSAP Animations:** Features `ScrollTrigger`, `ScrollSmoother`, and `SplitText` for smooth momentum scrolling and dynamic text reveal transitions.
- **🌗 Dark / Light Mode Support:** System-aware theme switcher with persistent preference storage via custom React hooks.
- **💼 Interactive Projects Showcase:** Interactive cards displaying full-stack projects (*Aura E-Commerce*, *Collaborative Notes App*, *Finflow*) with live demos and repository links.
- **📊 GitHub Contributions Heatmap:** Live open-source contribution calendar integrated using `react-github-calendar`.
- **📩 Functional Contact Form:** Direct message submission via **Web3Forms API** with type-safe schema validation powered by **Zod** & **React Hook Form**.
- **📱 Fully Responsive Design:** Clean, accessible, pixel-perfect layout optimized across mobile, tablet, and desktop viewports.

## 💻 Local Setup & Development Guide

### Prerequisites
- **Node.js** (v18.x or higher)
- **pnpm** (recommended) or **npm** / **yarn**

### Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mhmd-aho/portfolio-v3.git
   cd portfolio-v3
   ```

2. **Install dependencies:**
   ```bash
   pnpm install
   # or npm install
   ```

3. **Environment Setup:**
   Create a `.env` file in the root directory:
   ```env
   VITE_WEB3FORMS_API_KEY=your_web3forms_access_key
   ```

4. **Start Development Server:**
   ```bash
   pnpm dev
   # or npm run dev
   ```
   Open `http://localhost:5173` in your browser.

5. **Build for Production:**
   ```bash
   pnpm build
   # or npm run build
   ```
